Telegram Bot yaratish — Aiogram 3+

Talab qilinadigan bilim: Python Foundation kursi (o'zgaruvchilar, tsikllar, funksiyalar, OOP asoslari, fayllar bilan ishlash, JSON)

Jami: 19 dars — 14 nazariy mavzu + 1 takrorlash/EXAM + 3 amaliy loyiha + 1 yakuniy taqdimot

---

1. Kirish: Telegram Bot API va Aiogram bilan tanishish
✔️ Bot nima va Telegram Bot API qanday ishlaydi (update, message, webhook/polling)
✔️ Aiogram nima — to'liq asinxron (async) framework, boshqa kutubxonalardan (pyTelegramBotAPI, python-telegram-bot) farqi
✔️ @BotFather orqali bot yaratish: token olish, nom/rasm/tavsif sozlash
✔️ Muhitni tayyorlash: virtual environment (venv), pip install aiogram
✔️ python-dotenv — tokenni .env faylda xavfsiz saqlash
✔️ Birinchi oddiy bot: polling orqali ishga tushirish (echo bot)

2. Aiogram arxitekturasi: Bot, Dispatcher, Router
✔️ Bot obyekti — Telegram serveriga so'rov yuboruvchi
✔️ Dispatcher — kiruvchi update'larni handlerlarga yo'naltiruvchi
✔️ asyncio asoslari: async def, await, asyncio.run() — nega aiogram asinxron ishlaydi
✔️ Router — handlerlarni mantiqiy guruhlash (user_handlers.py, admin_handlers.py)
✔️ Handler ro'yxatdan o'tkazish: @router.message(), @router.callback_query()
✔️ dp.include_router() — routerlarni Dispatcher'ga ulash
✔️ Professional loyiha strukturasi: handlers/, keyboards/, database/, utils/, config.py, main.py

3. Komandalar, matnli xabarlar va content-turlari
✔️ CommandStart() va Command("nomi") filterlari
✔️ Message obyekti: message.text, message.from_user, message.chat, message.date
✔️ message.answer() va message.reply() farqi
✔️ Content-turlari: photo, video, document, voice, audio, sticker, location, contact
✔️ ContentType filter — faqat kerakli turdagi xabarni qabul qilish
✔️ parse_mode — HTML va MarkdownV2 bilan matnni formatlash (bold, italic, link)

4. Filterlar va Magic Filters (F)
✔️ Built-in filterlar: Command, CommandStart, Text
✔️ Magic filter — F obyekti: F.text, F.photo, F.text.contains(), F.text.startswith()
✔️ Filterlarni birlashtirish: & (va), | (yoki), ~ (emas)
✔️ Custom filter yaratish — masalan, faqat admin uchun filter
✔️ StateFilter haqida qisqacha (FSM bilan bog'liq, 7-darsda chuqur o'rganiladi)

5. Reply Keyboard (oddiy klaviaturalar)
✔️ ReplyKeyboardMarkup va KeyboardButton
✔️ ReplyKeyboardBuilder — dinamik klaviatura qurish, .adjust()
✔️ resize_keyboard, one_time_keyboard, input_field_placeholder
✔️ ReplyKeyboardRemove() — klaviaturani olib tashlash
✔️ Amaliy misol: bot uchun asosiy menyu

6. Inline Keyboard va CallbackQuery
✔️ InlineKeyboardMarkup va InlineKeyboardButton
✔️ InlineKeyboardBuilder, .adjust() — tugmalarni qatorlarga joylash
✔️ callback_data — tugmaga "yashirin" ma'lumot biriktirish
✔️ @router.callback_query(F.data == "...") handler
✔️ callback.answer() va callback.message.edit_text()
✔️ Amaliy misol: sahifalash (pagination), Ha/Yo'q tasdiqlash tugmalari

7. FSM (Holatlar mashinasi) — I qism
✔️ FSM nima va nima uchun kerak — ko'p bosqichli forma/dialog
✔️ StatesGroup va State — holatlarni e'lon qilish
✔️ state.set_state() — foydalanuvchiga holat berish
✔️ state.update_data() va state.get_data() — ma'lumotni vaqtincha saqlash
✔️ Har bir holat uchun alohida handler yozish
✔️ Amaliy misol: ro'yxatdan o'tish (ism → yosh → telefon)

8. FSM — II qism: Storage va murakkab dialoglar
✔️ state.clear() — forma tugaganda holatni tozalash
✔️ Storage turlari: MemoryStorage (oddiy) vs RedisStorage (production uchun)
✔️ "Ortga" tugmasi bilan bosqichlar orasida yurish
✔️ FSM + Inline Keyboard birgalikda ishlatish
✔️ Amaliy loyiha: buyurtma qabul qilish dialogi

9. Middleware
✔️ Middleware nima — handlerdan oldin/keyin ishlaydigan qatlam
✔️ Outer middleware vs Inner middleware farqi
✔️ Custom middleware: foydalanuvchini avtomatik bazaga yozish
✔️ Throttling middleware — spam/flooddan himoya
✔️ Middleware orqali handlerga qo'shimcha obyekt (masalan, DB session) uzatish

10. Ma'lumotlar bazasi bilan ishlash
✔️ Botga nega baza kerak (foydalanuvchilar, buyurtmalar, statistika)
✔️ SQLite va PostgreSQL farqi, qachon qaysi birini tanlash
✔️ SQLAlchemy (async) yoki aiosqlite bilan ulanish
✔️ Model yaratish: User, Order kabi jadvallar
✔️ CRUD amallar — async metodlar bilan qo'shish/o'qish/yangilash/o'chirish
✔️ Baza sessiyasini middleware orqali handlerlarga uzatish

11. Media va fayllar bilan ishlash
✔️ Fayl yuborish: FSInputFile (lokal), URLInputFile (link orqali)
✔️ Foydalanuvchi yuborgan faylni yuklab olish — bot.download()
✔️ Media guruh (albom) yuborish — MediaGroupBuilder
✔️ Voice va audio farqi
✔️ Telegram tomonidan fayl hajmi cheklovlari

12. Qo'shimcha imkoniyatlar
✔️ Bot komandalarini menyuga chiqarish — set_my_commands()
✔️ Deep linking — /start orqali maxsus parametr (referal/invite tizimi)
✔️ Kanal/guruhga a'zolikni tekshirish — chat_member statusi
✔️ Inline mode (InlineQuery) — qisqacha kirish

13. Xatoliklarni boshqarish va Logging
✔️ try/except bilan API xatolarini ushlash (masalan, botni bloklagan foydalanuvchi)
✔️ Global error handler — @router.error()
✔️ logging moduli — botning ishlashini fayl/konsolga yozib borish
✔️ Foydalanuvchiga tushunarli xato xabari ko'rsatish

14. Bot deploy qilish
✔️ Polling vs Webhook — farqi va qachon qaysi birini tanlash
✔️ .env va muhit o'zgaruvchilari — tokenni production'da xavfsiz saqlash

✔️ Webhook'ni aiohttp/FastAPI orqali ishga tushirish
✔️ Docker bilan konteynerlashtirish (qisqacha kirish)
